# Director Angel OS v0.1.0

`Director Angel OS` is a role-driven TypeScript Agent OS for turning defined positions into governed, session-aware, tool-using AI operators.

It treats the job as the runtime unit: role -> responsibility -> session -> tools/models/policy -> task execution -> evidence -> memory -> reviewed evolution.

The current public release demonstrates the Director role: planning, task shaping, evidence capture, review, and controlled learning. Director is the first demonstration role, not the product ceiling.

The product stance is practical: Director Angel is the operator of creative tools, not another isolated generator. It can learn production experience, operate connected external tools and web surfaces under policy, capture evidence, and improve the next run through review.

The release message is direct: prompt wrappers were the past; custom role-driven digital operators are the future. `Director Angel OS` is the operating layer that makes that future inspectable, recoverable, and governable.

## What This Release Includes

- session-aware runtime with journal, checkpoint, resume, and recovery
- tool / model / policy boundaries instead of a single giant `runAgent`
- CLI, gateway, and worker-jobs entrypoints
- task plane primitives for todos, delegation, verification, proposals, and outbox handling
- Host API external tool control plane for tool catalog, effective tools, invocation, and model adapter visibility
- bounded integration surfaces for `moyin-creator` / 魔因漫创 and ComfyUI, including ComfyUI import/export and workflow interop
- external creative-surface positioning for tools and web platforms such as Doubao, Jimeng, and Kling when connected through authorized adapters, browser automation, Host API tools, or handoff workflows
- adapter registry and governed plugin contracts for tools, providers, memory providers, and external knowledge connectors
- a controlled proposal -> review -> safe apply -> reload -> rollback lane for learned skills
- a role-first positioning layer for changing duties, supervising responsibilities, and growing operating memory
- Director-role demonstration content for the first public release
- regression gates and operator-facing documentation

## Launch Boundary

This release is intentionally bold in direction and strict in execution:

- role-driven agents are the product direction
- the current release demonstrates Director responsibilities while leaving the direction open for custom user-defined roles
- Director Angel operates creative tools; it does not claim to replace every named creative platform
- external tool and media integrations run through health, policy, approval, evidence, and degrade boundaries
- ComfyUI import/export and interop outputs require validation before execution or downstream handoff
- plugin support means controlled in-repo plugins and governed contracts, not a public plugin marketplace
- self-evolution runs through reviewable proposals
- new learned behavior is bounded by reload visibility
- rollback v1 restores approved snapshots
- workers propose; operators approve
