# Director Angel OS v0.1.0

`Director Angel OS` is a TypeScript AI Agent operating system skeleton.

If the final agent product is the car, `Director Angel OS` is the chassis underneath it: session runtime, tool boundaries, control plane, memory boundaries, and a controlled learning lane that you can inspect instead of blindly trusting.

## What This Release Includes

- session-aware runtime with journal, checkpoint, resume, and recovery
- tool / model / policy boundaries instead of a single giant `runAgent`
- CLI, gateway, and worker-jobs entrypoints
- task plane primitives for todos, delegation, verification, proposals, and outbox handling
- a controlled proposal -> review -> safe apply -> reload -> rollback lane for learned skills
- regression gates and operator-facing documentation

## What This Release Does Not Claim

- this is not a ready-made vertical agent product
- this is not an unrestricted self-rewriting runtime
- this is not yet a public plugin marketplace or a stable public SDK

## Recommended First Run

From the repository root:

```sh
pnpm install
pnpm --filter @hotflow/cli dev -- doctor --json
pnpm --filter @hotflow/cli dev -- run "Read README.md and summarize this project."
pnpm --filter @hotflow/cli dev -- golden-path README.md
```

## Release Boundary

This first public release focuses on one thing: giving teams a serious Agent OS chassis they can actually understand, run, and extend without rebuilding the operating layer from scratch.
