# Director Angel OS v0.01 / v0.0.1

## 中文

`Director Angel OS v0.01` 是职位驱动 Agent OS 的第一个公开开发者预览版。

它的定位很明确：先定义一个职位，再锁定这个职位的职责边界，让系统把会话、工具、记忆、证据、复盘、审核和持续进化都绑定到这个岗位上。

这个版本以“导演 Director”作为演示职位。导演是当前示例，不是系统上限。Director Angel OS 的长期方向，是让用户可以自定义职位、职责边界、工具权限、记忆访问范围、任务路由、验证规则和进化路径。

Director Angel 不是又一个创作生成器。它更像创作工具的操盘手：学习真实生产经验，把经验沉淀成有边界的操作记忆，在合规授权的范围内选择合适的软件、插件、网页平台或本地服务执行任务，记录证据，再通过复盘持续改进。

### 发布资产

- macOS arm64 桌面端预览 zip：`Director Angel-0.0.1-arm64-mac.zip`
- macOS release blockmap：`Director Angel-0.0.1-arm64-mac.zip.blockmap`
- GitHub Release 附件名：`Director.Angel-0.0.1-arm64-mac.zip`、`Director.Angel-0.0.1-arm64-mac.zip.blockmap`
- App 版本：`0.0.1`
- Bundle id：`com.hotflow.director-angel`
- App 图标：用户提供的 Director Angel 操盘手 logo

### 本次新增

- 提供 Director Angel OS 的首个 Mac 桌面端打包版本。
- App/package 版本设置为 `0.0.1`，作为第一个公开预览版。
- 桌面运行时打包现在包含 CLI、Host API、worker/runtime packages、内部插件 dist 文件和必要运行依赖。
- 打包后的桌面端默认把可写数据放到 macOS Application Support，不再写入源码仓库。
- API 设置页新增 `memefast.top` 推荐入口，用户可以直接跳转到外部服务页面。
- `memefast.top` 入口通过固定安全的桌面动作打开；Director Angel 不处理付款信息，也不保存外部平台的支付数据。
- Mac 图标生成使用用户提供的 `download.png` 源图，产出 `.icns` 和桌面 PNG 资源。
- 打包流程会在 zip 创建前清理 macOS AppleDouble `._*` 文件。

### 当前已包含

- 职位驱动 Agent OS 运行时，具备 session、memory、evidence、task、review 等边界。
- Director 导演职位演示界面，用于规划、操作、复盘和从创作任务中学习。
- `moyin-creator` / 魔因漫创集成，通过本地 `moyin` CLI/控制平面边界接入。
- ComfyUI 媒体 adapter/provider bridge，支持 workflow 导入/导出、互操作草案、诊断和生命周期界面。
- Host API 外部工具控制平面，支持 catalog/effective/invoke/model-adapter 可见性。
- 受控插件契约和仓库内插件能力。
- 受控学习通道：经验 -> skill proposal -> review -> safe apply -> reload visibility -> rollback。

### 使用边界

- 这是未签名的 macOS Developer Preview zip，不是已公证的 App Store 风格安装包。
- macOS 首次打开时可能需要用户手动确认，因为当前 app 尚未签名/公证。
- 当前桌面端发布形态是 zip，不是 DMG。
- 本预览版有意关闭 `asar`，因为运行时会直接导入 workspace package dist 文件。
- 外部供应商仍需要用户自己的账号、API key、本地服务、浏览器会话或已授权 adapter。
- 豆包、即梦、可灵、ComfyUI、`moyin-creator` 等外部创作平台，是 Director Angel 可以通过批准的集成路径去操作的外部界面；本版本不声称与所有具名平台都有官方原生合作关系。
- `memefast.top` 是推荐的外部打开入口。付款、账号创建和 API key 管理都在外部站点由用户自行控制。

## English

`Director Angel OS v0.01` is the first public developer preview of the role-driven Agent OS.

The product direction is clear: define a position, lock its responsibility boundary, and let the runtime bind sessions, tools, memory, evidence, review, and evolution to that job.

This release demonstrates the Director role. Director is the example role, not the ceiling. The long-term OS direction is user-defined roles whose tools, memory access, task routing, verification rules, and evolution path change with the position.

Director Angel is not another creative generator. It is the governed operator of creative tools. It learns production experience, stores that experience as bounded operating memory, chooses the right approved tool or web surface, records evidence, and improves through review.

### Release Assets

- macOS arm64 desktop preview zip: `Director Angel-0.0.1-arm64-mac.zip`
- macOS blockmap for release tooling: `Director Angel-0.0.1-arm64-mac.zip.blockmap`
- GitHub Release asset names: `Director.Angel-0.0.1-arm64-mac.zip`, `Director.Angel-0.0.1-arm64-mac.zip.blockmap`
- App version: `0.0.1`
- Bundle id: `com.hotflow.director-angel`
- App icon: user-provided Director Angel operator logo

### What Is New

- Initial Mac desktop package for Director Angel OS.
- App/package version set to `0.0.1` for the first public preview.
- Desktop runtime packaging now includes the CLI, Host API, worker/runtime packages, internal plugin dist files, and required runtime dependencies.
- Packaged desktop defaults to writable user data under macOS Application Support instead of writing into the source repository.
- API settings now include a recommended `memefast.top` opening/purchase entry so users can go directly to the external provider page.
- The memefast link is opened through a fixed, safe desktop action; Director Angel does not process payment information or store external platform payment data.
- Mac icon generation uses the user-provided `download.png` source and produces `.icns` plus desktop PNG assets.
- Packaging removes macOS AppleDouble `._*` files before zip creation.

### Included Today

- Role-driven Agent OS runtime with session, memory, evidence, task, and review boundaries.
- Director-role demonstration surface for planning, operating, reviewing, and learning from creative work.
- `moyin-creator` / 魔因漫创 integration through the local `moyin` CLI/control-plane boundary.
- ComfyUI media adapter/provider bridge with workflow import/export, interop drafts, diagnostics, and lifecycle surfaces.
- Host API external tool control plane for catalog/effective/invoke/model-adapter visibility.
- Governed plugin contracts and in-repo plugin surfaces.
- Controlled learning lane: experience -> skill proposal -> review -> safe apply -> reload visibility -> rollback.

### Launch Boundary

- This is an unsigned macOS Developer Preview zip, not a notarized App Store-style installer.
- macOS may require manual confirmation on first open because the app is not signed/notarized yet.
- The desktop package currently ships as a zip target, not DMG.
- `asar` is intentionally disabled in this preview because the runtime imports workspace package dist files directly.
- External providers still require user-owned accounts, API keys, local services, browser sessions, or approved adapters.
- Named creative platforms such as Doubao, Jimeng, Kling, ComfyUI, and `moyin-creator` are external surfaces Director Angel can operate through approved integration paths; this release does not claim official native partnership with every named platform.
- The `memefast.top` entry is a recommended external opening path. Payment, account creation, and API key management happen on the external site under the user's control.
